# Chaos Market AI

Evidence-first crypto market intelligence agent for Binance Agent OS workflows.

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run test
npm run lint
npm run build
```
